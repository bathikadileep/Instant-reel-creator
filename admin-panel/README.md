# Instant Reel - React Admin Panel

Production-grade web admin console for **Instant Reel**, managing on-demand reel videographers and bookings across **Maripeda, Mahabubabad, Khammam, and Warangal**.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 8 (TypeScript)
- **Styling**: Tailwind CSS v4 (Obsidian Dark Theme)
- **Data Fetching**: TanStack React Query v5
- **Networking**: Axios with JWT Interceptors
- **Icons**: Lucide React

## 🚀 Key Modules
1. **Dashboard**: Live shoot metrics, 10-minute SLA monitors, Telangana regional hub volume (Maripeda, Mahabubabad, Khammam, Warangal), and recent shoots feed.
2. **Booking Management**: Real-time filters by hub and 8-stage workflow status, full shoot inspector with interactive milestone timeline, and creator dispatch modal.
3. **Creator Management**: Local videographer directory, 4K camera gear details, star ratings, online/offline availability toggling, and verification badge management.
4. **Customer Management**: Customer accounts directory, booking frequency, cumulative spend metrics, and account access suspension/reactivation.
5. **Revenue Reports**: Financial analytics, automated 80/20 revenue split (80% creator payouts / 20% platform commission), regional hub breakdown, and financial CSV export.

## 💻 Quick Start

```bash
cd admin-panel
npm install
npm run dev
```

Admin panel opens on `http://localhost:3000`.
